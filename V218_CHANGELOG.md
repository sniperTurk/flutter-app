# v218 — Global ammunition reference registry

Added `data/global_ammunition_brands.csv` with 28 user-supplied global ammunition, projectile, case, and propellant brand/group entries. All records remain `user_supplied_unverified`; claims about ownership, manufacturing origin, product specifications and current availability are not treated as verified. Grouped labels (CCI/Speer, Sterling/Turaç, Magtech/CBC) are reference entries, not assertions that the labels are interchangeable product manufacturers. No ballistic parameters or live production ammunition models were fabricated. Existing PCP and firearm catalog routing remains unchanged. Added `tools/test_global_ammunition_brands.py` for duplicate IDs, completeness, provenance, category constraints and isolation from the production catalog.
