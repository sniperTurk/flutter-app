# Taslaklar — Ö11, Ö10, Ö9 (2026-10-12)

Kod yazılmadan önce çizilen sayfa taslakları (SVG kaynak + PNG). Sayılar
örnektir; uygulamada kutular boş gelir (kutu içinde örnek değer yok).

- `o11_kontrol_listesi` — Araçlar > Atış Öncesi Kontrol: işaret kutuları, her
  maddede ⓘ, sayaç, Temizle. SFP maddesi yalnız dürbün FFP değilse.
- `o10_sifir_grubu` — Araçlar > Sıfır Grubu: Mesafe | Kare boyu, kareli
  hedefe dokunarak vuruş, merkez (kırmızı artı), sonuç kutuları, belirsizlik
  notu, onaylı "Sıfır ofsetine aktar".
- `o9_atis_gunlugu` — Araçlar > Atış Günlüğü: kayıt formu (Mesafe tam satır,
  diğerleri ikişer), soğuk namlu özeti susturucuya göre, kayıt listesi.

Yazı tipi: tema (`MenzilType.family`, 2026-10-12 itibarıyla Inter).
