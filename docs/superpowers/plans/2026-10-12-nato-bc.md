# NATO standart mermi BC'si Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** BC'si boş MKE/askerî fişeklere, eşlendikleri NATO standart mermisinin resmî raporundaki BC'yi vermek; Profil'de BC kutusunu doldurmak ve ⓘ'de nasıl eklendiğini söylemek.

**Architecture:** Veri `data/nato-bc` dalında (`data/nato-bc/nato_bc.json`, 26 kayıt). `tools/data_gen/generate_profile_lists.py` bu dosyayı `tools/data_gen/nato` çalışma ağacından okur, `status == "uygulandı"` kayıtların BC'sini `FactoryAmmo`'ya `bcSource: 'nato-standard'`, `bcStandard`, `bcReport`, `bcSourceUrl` ile yazar. ⓘ metni `ProfileFieldInfo.bcNatoStandard(...)` üretir; `_factoryBcNote` bunu yalnız bu kayıtlar için ekler.

**Tech Stack:** Python 3 generator, Dart/Flutter, flutter_test.

**Spec:** Sahibinin görevi (2026-10-12, PR açıklamalarında aynen).

## Global Constraints

- Kaynak yalnız resmî, kamuya açık rapor (ARL/BRL/DTIC, NATO açık yayın). Forum/blog/bayi/ChairGun/Strelok/AB/JBM/QuickLOAD/GRT yasak.
- ⓘ metni: "MKE bu fişeğin BC'sini yayımlamıyor. Değer, aynı NATO standart mermisinin (ör. M80) resmi test raporundan alındı. Kendi tüfeğinizde fark olabilir; kutudaki ya da ölçtüğünüz değeri girebilir, Doğrulama ekranıyla düzeltebilirsiniz." (marka ve standart kayda göre).
- Kutu altında yardım yazısı yok; etiketlerde parantez yok; kalın yok; diğer fişeklerin ⓘ metni değişmez.
- MKE 23,7 m hızları seçilen BC modeliyle (G1/G7) namlu ağzına geri hesaplanır.
