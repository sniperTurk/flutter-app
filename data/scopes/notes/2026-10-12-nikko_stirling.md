## Data-quality issues seen on the site

- The spec tables use a generic header 'E/W range (MOA)' even on MIL scopes. Travel for the Diamond FFP 34mm PRR and 5-30x56 MRAD was set to null because the unit is ambiguous. The HMD 34mm models state 'MIL' explicitly (27 and 22 mrad).
- Click-value conflicts between the table and the feature text set click_value to null for UL1624, NSOC1824, NSOC1824 BDC, NSME1424, NDSI104056LRHMD and NPP41240. NPP41240 is MIL in the text but 1/4 MOA in the table, so click_unit is also null.
- Panamax 1 inch: several metric lengths (604.5, 607.5 and 609.5 mm) contradict the imperial lengths (12.0-12.2 in), so those lengths are null. NPGI451450AO weight is null (680 g vs 21.4 oz).
- Mount Master pages: the imperial table repeats the metric numbers verbatim, so the metric values and the feature text were used.
- Diamond Long Range HMD pages show only the shared HF/LR spec rows, and Diamond FFP 34mm PRR has a 30mm vs 34mm tube conflict (tube null).
- Airking 6-18x44 (and IR), plus Silver Crown 4x40 AO, have no row in their page's spec table. Only the title and the family feature text were used.
